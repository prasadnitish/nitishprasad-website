Decision
Use a lightweight JSON span contract for validation; keep OpenTelemetry as the scaled transport, not a prototype dependency.
Why

Privacy contract
Eval spans carry attributable model cost. Orchestrator spans deliberately use cost: null and retain only status, latency, and edge summaries.
